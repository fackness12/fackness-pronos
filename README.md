# 🏆 Fackness Pronos - Site Officiel

Bienvenue dans le dépôt de code source de **Fackness Pronos**, la plateforme d'investissement sportif intelligent. Ce site est une Landing Page (page unique) moderne, rapide et optimisée pour la conversion, déployée automatiquement sur Vercel.

---

## 🚀 Fonctionnalités du Projet

* **Design Moderne :** Conçu avec HTML5 et Tailwind CSS.
* **Responsive :** Parfaitement optimisé pour l'affichage sur smartphones (90% du trafic).
* **Paiement Intégré :** Liens de paiement FedaPay configurés pour accepter le Mobile Money (MTN, Moov, Wave, Orange) et les cartes bancaires.
* **Livraison Automatique :** Redirection instantanée vers le canal Telegram VIP après le succès du paiement.

---

## 🛠️ Maintenance & Déploiement

Ce projet est configuré en intégration continue avec **Vercel**. 

Chaque modification effectuée sur le fichier `index.html` dans ce dépôt GitHub déclenchera **automatiquement** une mise à jour du site en direct en moins de 10 secondes. Aucune manipulation supplémentaire n'est requise.
